01The game in one minute

You run a Mars base for 3 sols. Each morning you have 3 astronauts and 5 jobs, so 2 jobs are always left undone. Every job costs something today, and every skipped job costs something later. At the end, a domino chain shows which choice caused each problem. Then you try a different plan.

What kids learn: on Mars, every choice costs something, and help from Earth can't always arrive in time.

⚡ PowerSolar panels make it. Dust lowers it.
🫧 AirThe air machine needs power every night.
☢️ Space-ray meterCrew radiation dose. Lower is better.
🥬 FoodSmall counter from the greenhouse.

The 5 jobs

Job Costs today If done If skipped Real anchor
🧽 Clean panels (outside) worker + small dose Full power tomorrow Tomorrow's power ≈ ⅓ lower InSight dust storm: 425 → 275 Wh/sol
🥬 Greenhouse worker + 2 power +1 food −1 food; at 0 an astronaut is too tired game number
🛡️ Shelter worker + 1 power Dose halved today + tomorrow No protection in a storm game number
📡 Ask Earth worker + 1 power Morning: dust + storm-cloud forecast You plan blind Light delay 3–22 min; DONKI forecasts
🔬 Science trip (outside) worker + dose +1 science ⭐ No science —

The domino chain (our "wow" moment, first 8 seconds of the video)

Sol 1🧽✗ You skipped cleaning the panels
→
Sol 2⚡↓ Power about a third lower
→
Sol 2 night🥬✗ Not enough power for greenhouse + air
→
Sol 3😴 An astronaut is too tired to work

☀️ Particle burst: no warning

Arrives in tens of minutes, faster than any message from Earth. Real: 20 May 2024. Curiosity's radiation detector measured 8.1 mGy from one storm: more than a month of normal Mars radiation.

🌫️ Storm cloud: Earth can warn you

A CME takes days. NASA's DONKI forecast that the 23 May 2024 CME would brush past Mars on 28 May. That's what "Ask Earth" reveals: the message takes ~12 min; scientists study it overnight.

Score: ⭐ crew safe · ⭐ base running · ⭐ science goal. Losing never feels like punishment: "Here's what caused it. Try again."

04How to work

Set up once

Windows (PowerShell), then open a new PowerShell: 

winget install --id Git.Git -e
winget install OpenJS.NodeJS.LTS

Accept the GitHub invite, then:

git clone https://github.com/YYN192/impossible-solution
cd impossible-solution
npm install
npm run dev
# open localhost:5173/impossible-solution/

Every work session

git switch <your-branch>
git pull
# get everyone else's merged work:
git fetch && git merge origin/main

Every 30–60 minutes

# must pass before pushing:
npm run build && npm test
git add -A
git commit -m "Plan screen: tap astronaut then job"
git push

Then on GitHub: Compare & pull request → into main → wait for the green check → Merge. The live site updates in ~1 minute.

Team rules

  • Short kid sentences. Explain every science word. All text goes in src/i18n/en.json.
  • Buttons ≥ 44 px, keyboard + touch work, respect reduced motion.
  • Every number has a source or says "game number". Never call saved data "live".
  • Credit everything the same day: library, icon, font → CREDITS.md; AI use → docs/ai-usage-log.md.
  • No NASA logos. No faces or voices of team members (we're under 18) in the video or project page.
  • Small commits, main always works. Stuck for 20 minutes? Ask the team.
  • Merge conflict? Don't delete anything. Keep the right lines, remove the <<<< ==== >>>> markers, commit.
